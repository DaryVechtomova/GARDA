# Інтернет-магазин "GARDA"

## 🚀 Про проєкт

"GARDA" — це сучасний інтернет-магазин, розроблений на базі стеку **MERN (MongoDB, Express.js, React, Node.js)**. Він складається з трьох незалежних компонентів:

1.  **Backend (Express.js/Node.js)**: Серверна частина, що реалізує REST API для взаємодії з базою даних, обробки бізнес-логіки та автентифікації.
2.  **Frontend (React/Vite)**: Клієнтський інтерфейс для покупців, що дозволяє переглядати товари, робити замовлення та керувати своїм профілем.
3.  **Admin Panel (React/Vite)**: Окрема панель адміністратора для керування товарами, замовленнями, постачальниками, співробітниками та іншим контентом сайту.
4.  **Онлайн-примірочна (Three.js/Vite)**: Інтерактивний 3D-модуль для віртуальної примірки одягу на кастомізованій моделі.

## 🛠️ Технологічний стек

### Backend (Серверна частина)

- **Середовище виконання**: Node.js
- **Фреймворк**: Express.js
- **База даних**: MongoDB (з використанням Mongoose для моделювання даних)
- **Автентифікація**: JSON Web Tokens (JWT) з використанням `jsonwebtoken` та `bcrypt` для хешування паролів.
- **Обробка файлів**: Multer для завантаження зображень товарів.
- **Обробка платежів**: Stripe для онлайн-оплати.
- **Валідація**: Validator.js.
- **Середовище**: `dotenv` для керування змінними середовища.

### Frontend (Клієнтська частина) & Admin Panel (Панель адміністратора)

- **Бібліотека**: React (з використанням Vite як збирача проєкту)
- **Маршрутизація**: React Router
- **HTTP-клієнт**: Axios
- **Стилізація**: Tailwind CSS, PostCSS
- **Іконки**: React Icons
- **Сповіщення**: React Toastify
- **Форми**: React IMask (для масок вводу)
- **Декодування JWT**: `jwt-decode` (для адмін-панелі)

### Онлайн-примірочна

- **3D-графіка**: Three.js
- **Завантажувач моделей**: GLTFLoader, OrbitControls
- **Збирач проєкту**: Vite

## 📁 Структура проєкту

Проєкт організовано у монорепозиторій:

- **/backend**: Містить весь код серверної частини.
- **/frontend**: Основний клієнтський додаток (React).
  - **/fittingRoom**: Окремий вкладений проєкт віртуальної примірочної (Three.js).
- **/admin_panel**: Панель управління для адміністраторів та співробітників.

## 📋 Передумови

Перед початком переконайтеся, що на вашому комп'ютері встановлено:

- **Node.js** (версія 16.x або новіша) та **npm**.
- **Git** для клонування репозиторію.

## ⚙️ Інсталяція та запуск

Щоб запустити проєкт локально, виконайте наступні кроки. Кожен компонент системи (backend, frontend, admin_panel, fittingRoom) потрібно запускати в окремому вікні терміналу.

### Крок 1: Клонування репозиторію

```bash
git clone https://github.com/DaryVechtomova/GARDA.git
cd GARDA

```

Крок 2: Налаштування Backend

1. Перейдіть до директорії backend:

```bash
cd backend
```

2. Встановіть залежності та запустіть сервер:
   Відкрийте перший термінал у папці backend і виконайте:

```bash
npm install
npm run server
```

Сервер запрацює на http://localhost:4000.

Крок 3: Налаштування Frontend (Клієнтська частина)

1. Перейдіть до директорії frontend:
   Відкрийте другий термінал і виконайте:

```bash
cd frontend # Якщо ви в корені проєкту
```

2. Встановіть залежності та запустіть клієнтський додаток:

```bash
npm install
npm run dev
```

Сайт буде доступний за адресою http://localhost:5173.

Крок 4: Налаштування Admin Panel (Панель адміністратора)

1. Перейдіть до директорії admin_panel:
   Відкрийте третій термінал і виконайте:

```bash
cd admin_panel # Якщо ви в корені проєкту
```

2. Встановіть залежності та запустіть панель адміністратора:

```bash
npm install
npm run dev
```

Панель адміністратора буде доступна за адресою http://localhost:5174.

Крок 5: Налаштування Онлайн-примірочної

1. Перейдіть до директорії fittingRoom:
   Відкрийте четвертий термінал і виконайте:

```bash
cd frontend/fittingRoom
```

2. Встановіть залежності та запустіть примірочну:

```bash
npm install
npx vite
```

Онлайн-примірочна буде доступна на наступному вільному порту (зазвичай http://localhost:5175).

🐛 Вирішення поширених проблем
Помилки CORS: Перевірте, чи дозволяє ваш backend-сервер (cors у server.js) запити з адрес, на яких працюють клієнтські додатки (http://localhost:5173, http://localhost:5174).
Сервер не може підключитися до БД: Перевірте правильність MONGO_URI у файлі .env та переконайтеся, що ваша поточна IP-адреса додана до списку доступу в MongoDB Atlas.
Помилки при npm install: Спробуйте видалити папку node_modules та файл package-lock.json у відповідній директорії, а потім запустіть npm install знову.
